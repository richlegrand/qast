Getting Started

Install Python package dependencies and build the Rust encoder once.

Linux/macOS

python -m pip install -U pip
python -m pip install -e ".[all]"
python -m playwright install chromium
cargo build --manifest-path rust/qast-encoder/Cargo.toml --release

Windows PowerShell

py -m pip install -U pip
py -m pip install -e ".[all]"
py -m playwright install chromium
cargo build --manifest-path rust/qast-encoder/Cargo.toml --release

Verify

qast --help
qast-ui --help
# Windows:
.\rust\qast-encoder\target\release\qast-encoder.exe --help
# Linux/macOS:
rust/qast-encoder/target/release/qast-encoder --help

If browser capture is not needed, Playwright install can be skipped.
