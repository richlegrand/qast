Python API

Use qast programmatically for automation and scheduled playback.

One-shot

from qast import discover, cast

devices = discover()
cast("https://youtube.com/watch?v=...", device=devices[0])

Queue-based

from qast import Qast

q = Qast(device="Living Room TV")
q.add("screen", duration=30)
q.add("window:Grafana", duration=120)
q.add("https://youtube.com/watch?v=...")
q.play(repeat=True)

status = q.status()
print(status.state, status.now_playing, status.queue)
