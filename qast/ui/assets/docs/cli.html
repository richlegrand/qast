CLI Guide

qast accepts URLs, local files, capture sources, and playlists.

Common commands

qast "https://youtube.com/watch?v=..."
qast video.mp4
qast screen
qast window:Grafana@5m
qast --playlist morning.txt --repeat
qast -d "Samsung" video.mp4

Source syntax

  • <url-or-file>[@duration]
  • screen[@duration]
  • webcam[@duration]
  • window[:title][@duration] (Windows: use window:title)
  • browser:<url>[@duration]

Flags worth knowing

  • --repeat, --shuffle, --playlist FILE
  • --cookies-from-browser chrome for YouTube extraction issues
  • --preroll 5 to work around DLNA start truncation
  • --show-all to display all protocol variants
