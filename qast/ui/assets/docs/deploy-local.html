Local Deployment

Serve the marketing site, docs, and local admin UI from one process.

Run server

qast-ui --host 0.0.0.0 --port 8787

Routes

  • / - public site (production target: qast.nuts.services)
  • /docs - docs portal
  • /admin - local admin UI
  • /api/health - status endpoint
  • /api/ui-targets - route metadata

Deploy notes

  • For public hosting, route qast.nuts.services to /.
  • Keep /admin local-only or behind auth/VPN.
  • Link docs from site nav and from your GitHub README.
