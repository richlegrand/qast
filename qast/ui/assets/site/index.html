Open Source TV Casting Engine

Cast files, streams, screens, and webpages to real TVs from one CLI.

qast normalizes mixed media into one continuous stream so playback works consistently across Chromecast, DLNA, and Roku devices.

Start In 60 Seconds View Source

One input model

URLs, local files, browser pages, webcam, desktop capture, and piped ffmpeg data all flow through one queue.

Protocol-agnostic output

Use one command and let qast drive Cast, DLNA SOAP, or Roku ECP signaling automatically.

Deploy local

Run qast-ui to serve this site, docs, and your local admin UI from one local process.

Quick glance

qast "https://youtube.com/watch?v=dQw4w9WgXcQ"
qast screen
qast window:Grafana@5m
qast --playlist morning.txt --repeat
qast-ui --host 127.0.0.1 --port 8787
